# Joyce & Ken — Interactive Pop-Up Book Wedding Invitation

A mobile-friendly, interactive 3D pop-up-book style wedding invitation for GitHub Pages.

## Wedding details
- **Date:** May 11, 2027
- **Ceremony:** 2:00 PM — Parish of Immaculate Heart of Mary
- **Reception:** 3:30 PM — The Chandelier Events Place

## Files
- `index.html`
- `style.css`
- `script.js`

## GitHub Pages
1. Create/open your GitHub repository.
2. Upload the three files to the **root** of the `main` branch.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → /(root)**.
5. Save and open the GitHub Pages URL.

The invitation supports mouse/tap page turning, mobile swipe gestures, keyboard arrows, a replay button, animated fairy lights, floating magical dust, floral clusters, and subtle drifting petals.
